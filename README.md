# LUXE - Ultra-Premium Shopping Store

A modern, high-end e-commerce platform showcasing luxury brands and premium products with an elegant, immersive user experience.

![LUXE Banner](https://images.unsplash.com/photo-1557821552-17105176677c?w=1200&q=80)

## ✨ Features

### 🎯 Core Functionality
- **Product Catalog** - Curated collection of 29+ luxury products across 12 categories
- **Shopping Cart** - Add, remove, and manage items with real-time updates
- **Wishlist** - Save favorite items for later
- **Product Search** - Find products by name or brand
- **Category Filtering** - Browse by luxury categories (Men Fashion, Women Fashion, Watches, etc.)
- **Checkout Process** - Secure order summary and delivery options
- **User Authentication** - Login/Register system

### 🎨 Design & UX
- **Custom Cursor** - Interactive, brand-themed cursor experience
- **Particle Animation** - Subtle ambient particle effects
- **Smooth Scrolling** - Elegant page transitions and scroll animations
- **Responsive Design** - Fully mobile-optimized interface
- **Glass Morphism** - Modern glassmorphism UI elements
- **Dark Luxury Theme** - Premium dark mode with gold accents
- **Toast Notifications** - Real-time user feedback system

## 💻 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No dependencies or build tools required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Amin-perfect/E-commerce-website.git
   cd E-commerce-website
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your web browser
   # Or use Live Server extension in VS Code for better experience
   ```

### Local Development

```bash
# Option 1: Using Python
python -m http.server 8000

# Option 2: Using Node.js
npx http-server

# Then navigate to http://localhost:8000
```
